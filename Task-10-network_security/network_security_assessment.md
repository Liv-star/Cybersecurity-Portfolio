# Executive Summary

This security assessment evaluates the security posture of a local network using two industry-standard cybersecurity tools:

- Nmap for network discovery and port scanning.
- Wireshark for packet capture and traffic analysis.

The assessment identified active hosts, open ports, running services, and observed HTTP network traffic. Recommendations are provided to improve the network's security and reduce potential attack surfaces.

The objectives of this assessment were to:

- Discover devices connected to the network.
- Identify open ports and active services.
- Capture live network traffic.
- Analyze HTTP communication.
- Identify potential security risks.
- Recommend appropriate security controls.


# Security Observations

Open ports increase the network attack surface if not properly secured.

The following services were identified:

- SSH
- HTTP
- HTTPS
- DNS

These services should only remain enabled if required for business operations.

# Security Vulnerabilities Identified

Although no active attacks were detected, several potential security concerns were identified.

## Open Ports

Any unnecessary open ports could be exploited by attackers.

Recommendation:

- Close unused ports.
- Restrict access using a firewall.

---

## HTTP Traffic

HTTP traffic is transmitted without encryption.

Recommendation:

Use HTTPS whenever possible.

---

## Network Exposure

Devices responding to network scans may be discoverable by attackers.

Recommendation:

Disable unused services and enable firewall protection.

---

## Weak Access Controls

SSH should not allow password-only authentication.

Recommendation:

- Use SSH keys.
- Disable root login.
- Enable Multi-Factor Authentication where possible.

# Recommendations

To improve network security:

- Enable a firewall (UFW).
- Disable unused services.
- Use HTTPS instead of HTTP.
- Keep operating systems updated.
- Perform regular vulnerability scans.
- Monitor network traffic.
- Use strong authentication.
- Apply security patches promptly.
- Conduct regular security assessments.
- Implement intrusion detection systems.

---

# Conclusion

This assessment successfully demonstrated how Nmap and Wireshark can be used together to evaluate network security.

Nmap identified active devices and services, while Wireshark provided visibility into live network communications. Although no active threats were detected, several opportunities for improving security were identified, including reducing unnecessary open ports, encrypting communications, and strengthening access controls.

Regular network assessments are essential for maintaining a secure computing environment and reducing cybersecurity risks.
